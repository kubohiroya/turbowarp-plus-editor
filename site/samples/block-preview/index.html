ブロックアイコンのプレビューを試す

2つのシーンが入った編集用作品です。アイコンにマウスを重ねて静止画を確認し、クリックして動かしたり、配置を編集したりできます。

Try block icon previews

This editable project contains two scenes. Hover over an action icon for a still preview, or click an icon to play a scene and edit actor placement or animation settings.

プレビュー体験サンプルを開く サンプルSB3をダウンロード

まず開く

上のボタンから開くと、プレビューと組み込みYAML編集が有効になります。拡張の確認画面が表示された場合は、内容を確認してこの作品の拡張を許可してください。緑の旗を押す前から、ブロックのプレビューを操作できます。

右下の「ステージ」を選び、「コード」タブを開いてください。2つのsceneが見えます。最初に選ばれるスプライトには、この操作の案内も付けています。下にあるブロックへはコード領域をスクロールします。

順番に試す

対象操作確認すること
scene内のaction左端のアイコンにマウスを重ねるそのシーンの、そのactionまで進めた静止画が現れます。マウスを離すと閉じます。
sceneアイコンをクリックシーンを再生し、停止・再再生できます。
showアイコンをクリックし、プレビュー内のアクター本体をドラッグ。枠のふちもドラッグ本体で位置、枠のふちで表示スケールを変更できます。数値欄も連動します。
setSkinアイコンをクリックし、枠のふちをドラッグ衣装を変えた状態で表示スケールを調整できます。
moveToアイコンをクリックし、移動先・秒数・easingを変更変更のたびに移動を再生します。アクターのドラッグで移動先を設定できます。拡縮はshowまたはsetSkinで指定します。
say / think2つ目のsceneでアイコンをクリックし、文章・時間・stylesを変更文字送りと吹き出しの表示アニメーションを、その場で再生し直します。
sayText / thinkText文章の入力アイコンをクリックして文章・時間を変更固定入力の吹き出しも、変更した内容ですぐに再生されます。

保存・キャンセル・Undo / Redo

  1. showの位置やスケールを変えて保存し、ブロックの値が変わることを確認します。
  2. コード領域を選び、Undo / Redoで保存した変更を戻したり再適用したりします。
  3. 別のプレビューで値を変え、キャンセルします。保存前のブロックの値が保たれることを確認します。

編集した作品を残す場合はEditorの「ファイル」から別名で保存してください。元のサンプルを開き直すと、公開時の状態に戻ります。

この作品について

App rc.77の公開済み編集用runtimeと、オリジナルSVG素材から生成しています。元台本はpreview.k4.yml、生成元とハッシュはmetadata.json、素材の利用条件はLICENSEで確認できます。

通常のEditorではプレビューは既定OFFです。この作品の起動リンクはtwPlusBlockPreview=1とtwPlusYamlEditor=1を指定します。

Open the project

The button enables block previews and embedded YAML editing. If an extension review dialog appears, review it and allow this project’s extensions. You can try previews before clicking the green flag.

Select Stage in the lower right, then open the Code tab. It contains both scenes. The initially selected sprite also shows this instruction. Scroll the code area to reach later actions.

Try these actions

  1. Hover over an action’s left icon for a still image at that point in its scene. Move away to close it.
  2. Click a scene icon to play, stop and replay that scene.
  3. Click show. Drag the actor’s body to move it, and drag its bounding border to change its scale. The numeric fields update too.
  4. Click setSkin. Drag the border to change the actor’s scale with its other costume.
  5. Click moveTo. Change its destination, duration or easing to replay the motion immediately. You can drag the actor to set its destination. Use show or setSkin for scale.
  6. In the second scene, click say or think. Change text, duration or styles to replay text reveal and bubble animation.
  7. Click the text input icons for sayText or thinkText and edit text or duration to preview the fixed input immediately.

Save, cancel, undo and redo

Save a placement change, then focus the code area and use Undo / Redo. Change another preview and cancel it to keep the original block values. Save your edited project under a new name from the File menu. Reopening the public sample starts from its original state.
