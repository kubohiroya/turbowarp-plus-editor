# Scratch数値入力の仕様メモ（全角数字・小数・整数の扱い）

対象：TurboWarp-Plus-Editor の数値引数欄。2026年11月19日、code-views 0.22.1 と Editor の接続を確認。入力時の半角変換は実装済みで、追加の警告・実行前検査は提案です。

## 1. 背景と実装状況

- 数値の引数欄では、キーボードの文字制限だけでは日本語 IME の確定入力を制限できず、全角数字が残る場合がありました。現在は code-views の installBlockNumberInput を、Editor のブロック登録時に組み込んでいます。
- 対象は、Scratch Blocks の restrictor_（1文字ずつの入力制限）を持つ入力欄です。数値・整数・角度・リストの位置などの欄が含まれます。文字列の引数欄には適用しません。
- この文書は入力時の変換を説明します。Scratch 実行時のすべての数値変換や、標準 Scratch の公式仕様を定義するものではありません。

## 2. 数値と整数の用語（検討用）

- ScratchNumericInput と ScratchIntegerInput は、このメモで提案を整理するための独自名です。次の正規表現による値全体の検証は、現在の Editor には導入していません。既存の各欄の入力制限と検証に従います。
- ScratchNumericInput：座標・角度・秒数・拡大率などの一般の数値引数を想定します。
- ScratchIntegerInput：リストの位置・繰り返し回数など、整数を前提とする引数を想定します。
- これらは JSON Schema や ECMAScript の正式な型名ではありません。空白・Infinity・16進数などの実行時の扱いを変更する契約でもありません。

ScratchNumericInput

```regex
^[+-]?(\d+\.?\d*|\.\d+)([eE][+-]?\d+)?$
```

ScratchIntegerInput

```regex
^[+-]?\d+$
```

## 3. 入力時の処理（実装済み）

- 全角 ASCII の「！」〜「～」を半角に変換します。数字の０〜９、＋、－、．に加えて、ｅ・Ｅも変換対象です。NFKC を全面的に適用する処理ではありません。
- 「ー」「−」「‐」「‑」「–」を半角の - に、「。」を半角の . に変換します。
- 変換した文字列から、その入力欄の restrictor_ が受け付けない文字を取り除きます。例えば数字と符号・小数点を許す欄では、「１２あ３」は「123」、「－１２。５」は「-12.5」になります。小数点・負数・指数表記を入力できるかは、それぞれの欄の既存の制限に従います。
- IME の変換中は文字列を書き換えず、確定した compositionend で変換します。通常の入力や貼り付け後の input でも同じ処理を使います。
- 入力欄の値とカーソル位置を更新し、Scratch Blocks の既存の変更処理へ渡します。作品内の文字列や、外部から読み込んだ既存の値を一括変換する処理ではありません。

## 4. 確定時と通知の範囲

- 現在は入力欄の既存の確定・検証処理を使います。半角への変換通知や、不正な値を示す独自のエラーマークは追加していません。
- 「全角数字を半角に変換しました」という通知や、値全体を正規表現で検証して警告する機能は、今後の検討事項です。

## 5. 実行前の検査（未実装の提案）

- 全角の値を含む既存作品や、整数を想定する欄に小数が入った作品を、実行前に検査して警告する仕組みは未実装です。
- 導入する場合は、既存作品の実行結果を変えないこと、入力欄と実行時の変換を区別すること、誤検出と切り戻しを検討する必要があります。

## 6. 残る検討事項

- 独自の数値・整数検証を導入するか、各欄の既存の制限だけを使うか。
- 整数を前提とする欄で 1.0 をどう扱うか、通知や実行前検査を提供するか。
- 実行時の数値変換を文書化する場合は、対象 VM と引数の種類ごとに確認し、入力時の変換とは別に記録する。

## 7. 実装の参照先

- 確認対象は package-lock.json と一致する code-views 0.22.1 の公開アーカイブです。src/block-number-input.ts が変換・IME・入力制限の処理を持ち、Editor の site/plus-integration.ts が registerBlockShapes から接続します。
- 切り戻す場合は、Editor の接続と code-views の固定を検証済みの組み合わせへ戻して再ビルドします。入力時の処理を戻しても、すでに確定・保存した値は自動で元には戻りません。保存前の作品を保持してください。
