# 作品のプロパティと診断

追跡: [Issue #138](https://github.com/kubohiroya/turbowarp-plus-editor/issues/138)、[Issue #146](https://github.com/kubohiroya/turbowarp-plus-editor/issues/146)。
通常のエディタURLから、Fileメニュー最下部の「Project Properties…」（日本語では
「作品のプロパティ…」）と「Project Diagnostics…」（「作品の診断…」）を利用できます。
作品情報の `twPlusProjectTools` は起動時固定・既定ONです。URLへの指定は不要です。
`?twPlusProjectTools=1` でも有効になり、`?twPlusProjectTools=0` で作品情報を無効にできます。
空文字や不正な値もOFFとして扱います。変更後はページを再読み込みしてください。
診断と失敗通知は、作品情報のフラグにかかわらず利用できます。

## 作品情報

タイトル、複数行の作品概要、作者名、連絡先を編集し「適用」で確定します。タイトルはエディタ上部と
同期し、適用した変更は未保存の変更として扱います。「キャンセル」は作品と入力履歴を変更しません。

## 作品の診断

Fileメニュー最下部に「Project Diagnostics…」（「作品の診断…」）を表示します。
拡張選択画面を含め、右上の「拡張の検証・許可」は常設しません。失敗時は画面下部のsnackbarで知らせ、
「詳細ログを表示」から失敗した読み込みの診断画面を開けます。「閉じる」で通知だけを消しても診断記録は
残ります。通知は一覧の高さを変えず、詳細表示や通知を閉じる操作で作品・許可状態を変更しません。
警告と読み込み失敗のsnackbarは `site/styles/snackbar.css` の共通スタイルで画面下端に固定し、
「キャンセル・追加」の領域には重なって表示します。背景・文字・枠・影・操作ボタンを揃え、失敗通知が
表示されている間は警告のsnackbarを隠します。失敗通知を閉じるか詳細ログを開くと、警告の表示に戻ります。
実行許可のダイアログと中央の再試行表示は維持します。

Plus拡張の取得元・実行モード・SHA-256と、検証・認可・読み込み・再試行・失敗のイベントを確認できます。
通常のScratch/TurboWarp拡張について個別の検証・許可イベントを追加するものではありません。
診断はLoaderが実際に報告した内容です。ハッシュの一致は内容の一致を示し、作者の本人性や安全性の保証では
ありません。新たな実行許可の変更・取消操作はここにはありません。

最新5回の作品読み込みを区別して保持し、各回の最新50件を表示します。失敗した作品も読み込みの記録から
選べます。診断をコピーでき、クリップボードへの書き込みが使えない環境では選択可能なテキストを表示します。
診断はこのエディタを開いている間のメモリにだけ保持し、作品やブラウザの保存領域には書き込みません。
コピーには作品名、拡張の取得URLや失敗理由が含まれるため、共有前に内容を確認できます。

作者名と連絡先は、履歴からの選択と新規入力ができる入力欄です。適用した非空の値を、新しい順に
各5件、ブラウザのlocalStorageへ保存します。重複は先頭に移動します。ストレージが使えない場合は
開いている間だけ記憶します。履歴全体は作品に含めず、今回の入力値だけを作品に含めます。

連絡先は `mailto:` または `https:` のリンクを入力欄の下に表示します。メールアドレスのみの入力は
`mailto:` にします。作品概要はプレーンテキストとして編集し、プレビューでHTTPS URLをリンクにします。
Webリンクは別タブ、メールリンクは利用環境のメールアプリで開きます。HTMLは解釈しません。

作成日時と最終更新日時は表示専用です。新規作品の作成日時は初回の読み込み時に記録し、過去の作品で
不明な日時は「未記録」とします。作品情報・ブロックなどの内容が変わっているとき、作品ファイルの
生成成功時に最終更新日時を更新します。閲覧、`toJSON()`による参照、変更なしの再保存では更新しません。
ブラウザ外でのファイル書き込み成功までは観測できないため、ディスク上の更新日時とは異なります。

## 保存形式・互換性

SB3の `project.json.turboWarpPlusProject` に `schemaVersion: 1`、`title`、`description`、`author`、
`contact`、`createdAt`、`updatedAt` を保存します。これはPlus独自形式です。Plusで再読込すると復元します。
Sprite単体の書出しには含めません。拡張Manifestや承認履歴とは別の情報です。

未知のバージョンは上書きせず、作品情報の編集を無効化して元の値を保持します。v1内の未知フィールドも
保持します。標準Scratch/TurboWarpやフラグOFFのエディタで保存し直すと独自情報が失われる可能性があります。
作者名・連絡先は保存した作品を共有すると受け取り手にも表示されます。

## 構成と切り戻し

UI、履歴、保存管理は `site/project-tools/`、フラグの判定は `config/feature-flags.ts` が所有します。
GUIは任意のFileメニュー描画口とタイトル状態の接続だけを提供します。拡張の保存フックの後に作品情報の
フックを設置し、破棄時は逆順で解除します。作品情報がOFFの場合は読み込み結果だけを監視し、
作品情報の読み取り・タイトル復元・保存フック・作者履歴の保存は有効にしません。

即時の切り戻しは `twPlusProjectTools=0` を明示して再起動します。フラグOFF時は従来のメニュー・
保存動作です。診断とsnackbarはフラグOFFでも利用できます。保存済み情報のバックアップは保持してください。
今回の表示変更の切り戻しは対応するホスト差分のrevertです。公開版を戻す場合はGUIの接続口と対応する
ホスト変更を組にしてrevertし、保存再読込と通常のファイルメニューを確認します。

## 今回の受け入れ基準

- 通常起動・作品情報ONの両方で、拡張選択中を含め右上の常設ログがない。
- 失敗時だけsnackbarが現れ、「詳細ログを表示」で該当の失敗記録を開ける。
- 日英・明暗・狭幅で操作でき、詳細表示を閉じると元の操作へ戻れる。
- 成功・閉じる・詳細表示では作品や実行許可を変更しない。既存の承認と再試行を維持する。
- 作品情報OFFではメタデータの保存・タイトル復元・作者履歴を有効にしない。

## 既定ONの回帰確認

既定ONへの切替前に、作品情報の適用・キャンセル、タイトル同期、作者名/連絡先の履歴各5件、リンク、
別名SB3での保存再読込、診断コピー、失敗記録保持、キーボード、日英・狭幅・明暗の表示を検証しています。
既定値の変更では、通常URLと明示ONで両メニューが使え、明示OFFでは作品情報を変更しないことを確認します。
設定は起動時に読み、作品データや起動後のURL変更では切り替えません。Loaderの有効/無効とは独立しています。

配信全体の既定値を戻す場合は、既定ONへの切替PRをrevertしてCI成功後に再配信します。
作品に保存済みの独自情報はバックアップに保持し、既定値の切替だけで削除・移行しません。
