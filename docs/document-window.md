# 組み込み文書のウィンドウ操作

文書ダイアログに適用します。起動設定はありません。本リポジトリの `site/plus-integration.ts` が文書エディターを常にマウントし、登録された提供元が文書を所有するハットにだけファイルアイコンが付きます。

- タイトル部分をドラッグすると画面内で移動します。
- 四辺・四隅をドラッグするとサイズを変更します。最小サイズは360×280pxで、画面がそれより小さい場合は画面内に収めます。
- Xの左にある「全画面化」でブラウザー内いっぱいに広げ、「元のサイズに戻す」で直前の位置とサイズへ戻ります。
- 本文はスクロールし、タイトル・全画面化・閉じる・保存・キャンセルは固定表示します。
- VSCodeを閉じた後も「VSCodeで編集」を再び押せます。元のセッション・作業ファイル・Schema設定を再利用し、未反映の編集内容を上書きしません。起動失敗時も再試行できます。

## 満たすこと

- タイトルの移動、四辺・四隅のリサイズ、全画面化と位置・サイズ復元。
- 画面端、最小サイズ、320px・390px幅、画面サイズ変更時に操作ボタンへ到達可能。
- 未編集での外部編集復帰、変更済み草稿の保持、再起動失敗後の再試行。
- 同一作業ファイルとSchemaの再利用、認証・Origin制約、終了済みセッションと不正な作業ファイルの拒否。
- 既存の文書保存・取消・変換・作品切替を壊さない。

```sh
node --test test/yaml-build.test.ts test/yaml-cli.test.ts
```

## 実装の置き場所

ウィンドウ・プレビュー・保存・外部編集の実装は `@kubohiroya/turbowarp-document-editor` にあり、移動・リサイズ・最大化・再オープンもそちらで維持します。本リポジトリは文書エディターのマウント、ローカル補助プロセスの配信パス指定、ライセンス通知を担当します。元SB3とVSCodeの作業ファイルは、文書エディターの版を変えても保持されます。
