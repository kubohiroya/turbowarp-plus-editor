6.1 横型パレットからブロックを置く

Plus配置では、コード画面の上部にカテゴリが横に並びます。「動き」「見た目」「音」「イベント」「制御」「調べる」「演算」「変数」「リスト」「ブロック定義」の順で、機能拡張を追加するとそのカテゴリも加わります。変数とリストのブロックは、「変数」と「リスト」に分かれています。

カテゴリをクリックすると、その下にブロックの小窓が開きます。使いたいブロックをコード領域へドラッグします。小窓を閉じるには、Escを押すか、小窓の外をクリックします。小窓のスクロール位置はカテゴリごとに保持されます。

横型パレット · スクロール位置の復元

6.2 パレットのカテゴリ内でブロックを検索する

小窓の上部にある「ブロックを検索」に語句を入力すると、そのカテゴリの見出しとブロックの表示名を部分一致で絞り込みます。日本語入力にも対応しており、絞り込んだブロックもそのままドラッグして置けます。一致しないときは「一致するブロックがありません」と表示されます。

作品の中で使っているブロックを探すときは、メニューバーの作品全体の検索を使います。

カテゴリ内検索

6.3 カテゴリの小窓を見やすい大きさにする

小窓の右下にある斜線をドラッグすると、幅と高さを変えられます。変えたサイズはカテゴリごとにブラウザーに保存されます。ペインや画面が狭いときは表示できる範囲に収まり、十分な広さに戻ると保存したサイズで開きます。

大きな画面でパレットを常に表示しておきたいときは、ブロックパレットを別画面で開くこともできます。

小窓のリサイズ

6.4 カテゴリの順序を変える

カテゴリを長押しし、移動先を示す枠に合わせて離すと並べ替えられます。ドラッグ中は、つかんだカテゴリのプレビューがポインターに付いて動きます。パレットの外で離すか、Escを押すと取り消せます。ページを再読み込みすると初期の順序に戻ります。twPlusHorizontalBlockPalette=1 を付けて起動した場合は、パレットを右クリックして横表示と縦表示を切り替えられ、並べ替えた順序も引き継がれます。

カテゴリの並べ替え · ドラッグ中のプレビュー

6.5 ブロックパレットを別画面で開く

「編集パネルのレイアウト」から「ブロックパレットを別画面で開く」を選ぶと、横型パレットがブラウザーの別ウィンドウに移ります。左端の丸いカテゴリボタンでカテゴリを選び、ブロックをエディターのコード領域へドラッグして置きます。右上の「ブロックパレットのレイアウト」ボタンには現在の並び方がアイコンで表示されます。押すと「横並びにする」「縦並びにする」で並び方を切り替えられ、「このパネルを別画面から元に戻す」でエディター内に戻せます。

パレットの別画面 · 丸いカテゴリボタン · 並び方の表示

6.6 パレットに戻すとブロックを削除する

コード領域のブロックをパレットへドラッグすると、そこで離せば削除されることを示すゴミ箱が表示されます。パレットから取り出したブロックを戻すときも同じです。離さずにコード領域へ戻せば、削除は行われません。

削除予告 · 取り出したブロックを戻すとき

6.7 ミニマップとズームで長いコードを移動する

Plus配置では、コード画面右下のミニマップでブロック全体の位置を見渡せます。ミニマップとその下のボタンは、ポインターをコードパネルに重ねている間だけ表示されます。ミニマップの枠は現在の表示範囲です。離れたブロックへ移動するときは、ミニマップ内の移動先をクリックするか、枠をドラッグします。下に並ぶボタンで縮小・拡大したり、倍率を初期値に戻したりできます。

ミニマップを表示しないようにするには、twPlusWorkspaceMinimap=0 を指定します。

ミニマップの操作 · ズームと配置 · ポインターを重ねたパネルに表示

6.8 右クリックメニューで操作する

ブロック、コード領域の空白、スプライトのタイル、コスチュームや音などの右クリックメニューでは、各項目に操作を表すアイコンが付きます。

主な項目
右クリックする場所主な項目
ブロック複製、コメントを追加、ブロックを削除、スクリプトを書き出し、コピー。アドオンによる「スペースを確保」「すべてコピー」「ブロックをコピー」「ブロックを切り取り」
コード領域の空白取り消し、やり直し、きれいにする、コメントを追加、ブロックを削除、スクリプトを読み込み、貼り付け、コードの並びの見え方を変更する
スプライトのタイル開く、複製、書き出し、スプライト名の変更、削除、フォルダーを作成
背景のタイル開く、ステージを書き出し
コスチューム・音複製、書き出し、削除

このほか、アドオンが追加する項目（ブロックの画像書き出し、ローカル変数とグローバル変数の切り替え、最前面・最背面への移動など）にもアイコンが付きます。スクリプトの書き出し・読み込みとコピー・貼り付けの使い方は、スクリプトとステージを別作品へ転送するで説明しています。

コードの並びの見え方を切り替える

コード領域の空白を右クリックし、「コードの並びの見え方を変更する」から「通常配置の見え方」「Z配置の見え方」「N配置の見え方」を選びます。いまの見え方にはチェックが付きます。Z配置では行の順に、N配置では列の順に、スクリプトを詰めて並べて表示します。見え方を変えても、作品の中のブロックの位置と編集履歴は変わりません。

ブロックの位置そのものを並べ直したいときは、「編集」メニューの「コードブロックの再配置」を使います。開いているコードタブのスクリプトについて、「順序」（「Z方式（行順）」または「N方式（列順）」）と「方向」（「垂直」または「水平」）を選んでプレビューを確かめ、「再配置する」で確定します。再配置は「元に戻す」1回で戻せます。

別のスプライトのコードへブロックをコピーする

パネルを分割したり、コードパネルを別画面で開いたりして、同じ作品の2つのコードタブを並べます。一方のコード領域にあるブロックを、もう一方のコード領域へドラッグして離すと、そのスプライトへコピーされます。つながったブロックはスクリプト全体がコピーされ、コピー元のブロックは元の位置とつながりのまま残ります。コピー先では「元に戻す」で取り消せます。ドラッグ中にEscを押すと、コピーせずに終わります。
