6.1 横型パレットからブロックを置く

Plus配置では、コード画面上部のカテゴリをクリックすると、その下にブロックの小窓が開きます。使いたいブロックをコード領域へドラッグします。変数や自分で定義したブロック、追加した機能拡張のブロックも同じ方法で選べます。小窓を閉じるにはEscを押すか、小窓の外をクリックします。

カテゴリごとに、最後にスクロールした位置を覚えています。

横型パレット · スクロール位置の復元

6.2 パレットのカテゴリ内でブロックを検索する

小窓の上部にある「ブロックを検索」に語句を入れると、そのカテゴリの見出しとブロックの表示名の部分一致で絞り込めます。日本語入力にも対応し、絞り込んだブロックもそのままドラッグして置けます。一致しないときは「一致するブロックがありません」と表示されます。

作品の中にあるブロックを探すには、メニューバーの作品全体の検索を使います。

カテゴリ内検索

6.3 カテゴリの小窓を見やすい大きさにする

横型パレットでは、小窓の右下にある斜線をドラッグして幅と高さを調整できます。変更したサイズはカテゴリごとにブラウザーに保存されます。ペインや画面が狭いときは表示できる範囲に収まり、十分な広さに戻ると保存したサイズで開きます。

大きな画面でパレットを常に表示しておきたいときは、ブロックパレットを別画面で開くこともできます。 小窓のリサイズ

6.4 カテゴリの順序を変える

カテゴリを長押しし、移動先を示す印に合わせて離すと並べ替えられます。ドラッグ中はカテゴリのプレビューが表示されます。パレットの外で離すかEscを押すと取り消せます。ページを再読み込みすると初期の順序に戻ります。twPlusHorizontalBlockPalette=1 を付けて起動した場合は、パレットを右クリックして横表示と縦表示を切り替えられ、並べ替えた順序も引き継がれます。

カテゴリの並べ替え · ドラッグ中のプレビュー

6.5 ブロックパレットを別画面で開く

「編集パネルのレイアウト」から「ブロックパレットを別画面で開く」を選ぶと、横型パレットがブラウザーの別ウィンドウに移ります。左端の丸いカテゴリボタンでカテゴリを選び、ブロックをエディターのコード領域へドラッグして置きます。右上のボタンには現在の並び方が表示され、押すと「横並びにする」「縦並びにする」を切り替えられます。

パレットの別画面 · 丸いカテゴリボタン · 並び方の表示

6.6 パレットに戻すとブロックを削除する

コード領域のブロックをパレットへドラッグすると、そこで離せば削除されることを示すゴミ箱が表示されます。パレットから取り出したブロックを戻すときも同じです。離さずにコード領域へ戻せば、削除は行われません。

削除予告 · 取り出したブロックを戻すとき

6.7 ミニマップとズームで長いコードを移動する

Plus配置では、コード画面右下のミニマップでブロック全体の位置を見渡せます。枠は現在の表示範囲です。離れたブロックへ移動するときは、ミニマップ内の移動先をクリックするか、枠をドラッグします。下に並ぶボタンで縮小・拡大したり、倍率を初期値に戻したりできます。

ミニマップを外すには twPlusWorkspaceMinimap=0 を指定します。 ミニマップの操作 · ズームと配置

6.8 右クリックメニューで操作する

ブロック、コード領域の空白、スプライトのタイル、コスチュームや音などの右クリックメニューを整理し、各項目に操作を表すアイコンを付けました。

主な項目
右クリックする場所主な項目
ブロック複製、コメントを追加、削除、スクリプトを書き出し、コピー
コード領域の空白元に戻す、やり直し、きれいにする、コメントを追加、スクリプトを読み込み、貼り付け
スプライトのタイル開く、複製、書き出し、名前を変える、削除、フォルダーを作成
コスチューム・音複製、書き出し、削除

アドオンが追加する項目（ブロックの画像書き出し、ローカル変数とグローバル変数の切り替え、最前面・最背面への移動など）にもアイコンが付きます。スクリプトの書き出し・読み込みとコピー・貼り付けの使い方はスクリプトとステージを別作品へ転送するで説明しています。
