Making projects with TurboWarp Plus

This guide covers TurboWarp Plus from start to finish across 12 topic pages: opening a project, arranging the screen, editing while searching the whole project, managing it with Git, handing it over as an SB3 or a single HTML file, and developing it on GitHub.

Open the editor in English · SB3 compatibility with Scratch and TurboWarp, and feature list (Markdown) · How the screenshots were taken

TurboWarp Plus Editor opens SB3 files saved by both Scratch 3 and standard TurboWarp. Some features that Plus builds into the editor require an extension that the project loads (a Scratch or TurboWarp extension), or data made for that extension.

This guide calls the editor published on GitHub Pages "the public editor (GitHub Pages)", a web build or supported desktop build with a GitHub connection configured "an editor with a GitHub connection", and unreleased builds such as the local integration build or the desktop development build "development builds". Unless a section names the version it was checked on, command names and layouts were checked on the public editor as of November 14, 2026 (TurboWarp Plus Editor 0.2.0-rc.4). The label "In development" marks features that are not yet in the public editor and were checked on a development build, "Prototype" marks features that are available on the public editor but limited in scope, and "Requires a supported extension" marks features that need a matching extension. Screenshots show the screen at the time they were taken, with the editor running in English, except where a caption notes the Japanese UI.
