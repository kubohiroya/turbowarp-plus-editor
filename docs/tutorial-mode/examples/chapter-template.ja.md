## 配布前の確認

- [ ] 対象IDが実在し、一意に解決する。
- [ ] 許可した場所だけを、複数の操作経路で編集できる。
- [ ] 制御役と台本を保護し、作品の再生を続けられる。
- [ ] 試行は作品全体を止めず、変更後の処理を実行する。
- [ ] 古い通知・二重クリックで進行しない。
- [ ] 長い読取り時間、閉じる、停止、再開、スキップに対応する。
- [ ] 設定、作品、進行が保存・再読込・次章で保たれる。
- [ ] 小さい画面、キーボード、日本語入力、音なしで確認した。
- [ ] 素材の権利と生成元、対応版、ハッシュを記録した。
- [ ] 未実装の設定や接続を、動作確認済みとして案内していない。
